# Social Comments

Currently, Dream supports these comment systems:

- [Disqus](https://disqus.com/)
- [utterances](https://utteranc.es/)
- [Valine](https://valine.js.org/en/)
- [Waline](https://waline.js.org/en/)
- [Twikoo](https://twikoo.js.org/en/)

## Disqus

In `hugo.toml`, set:

```toml
[services]
[services.disqus]
shortname = "..."
```

> [!WARNING]
>
> You may have used `disqusShortname = "..."` before. This is deprecated in Hugo `0.120.0`.
>
> Please upgrade to the new configuration. See https://gohugo.io/content-management/comments/#add-disqus for more details.

Disqus comments appear on [posts](post-page.mdx) and at the bottom of the standalone [About page](about-page.md).
If your About page is headless, remove `headless: true` from `content/about/index.md` to publish the page and show the existing discussion there.

### Compatible with oklch colors

Set the color scheme to **Auto** in your Disqus admin settings so that Disqus can detect the page's colors.
Dream reloads Disqus when you switch between light and dark mode, including changes to your system preference in automatic mode.

Dream includes compatible colors for Disqus comments and Recommendations because Disqus cannot parse the theme's OKLCH colors.
The defaults match the `emerald` and `forest` themes. No custom CSS is required for these themes.

If you use [other themes](light-and-dark-mode.md), override these colors in `static/css/custom.css` with hex or RGB values:

```css
.light #disqus_thread,
.light #disqus_recommendations {
  background-color: #fff;
  color: #333c4d;
}

.dark #disqus_thread,
.dark #disqus_recommendations {
  background-color: #171213;
  color: #cbc9ca;
}
```

To get the `background-color` and `color` values for your themes, inspect your site in the browser.

1. Open the browser's developer tools (`F12`) and select the `<html>` element in the **Elements** tab.
2. In the **Computed** tab, look for `background-color` and `color`. Expand each property to find its rule in the **Styles** tab.
3. Open the color picker for each value and switch its format to **HEX**. Copy the values into the matching light or dark rules in `static/css/custom.css`.
4. Switch to the other mode and repeat for that theme.

Include the file in `hugo.toml`:

```toml
[params]
[params.advanced]
customCSS = ["css/custom.css"]
```
